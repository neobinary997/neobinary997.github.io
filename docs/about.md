# 关于本站

这是一个基于 **VitePress** 构建的个人技术博客，用于沉淀和深度解读优质技术文章。

## 本站做什么

- **精读原文**：选择有深度、有干货的技术文章进行精读；
- **结构化拆解**：将长文拆解为「核心主张 → 关键设计 → 工程细节 → 延伸思考」的层次结构；
- **持续沉淀**：每篇解读都保留原文出处、链接，方便回溯原文；
- **快速订阅**：支持 [RSS 订阅](/feed.xml)，及时获取最新文章。

## 内容方向

本站内容围绕 AI Agent 全生命周期，按五大方向组织：

| 方向 | 关注内容 |
|------|----------|
| Agent 系统构建 | Agent 架构设计、上下文工程、状态管理、工具调用 |
| 业务落地 | 行业场景、产品化、商业化实践 |
| 工程化处理 | Harness 工程、架构框架、分层设计、安全防护 |
| 可观测性 | 评测体系、监控、trace 分析、日志 |
| Ops | 部署运维、CI/CD、灰度发布、SRE 实践 |

浏览时可以使用[文章列表](/posts/)页顶部的分类筛选，快速定位感兴趣的方向。
